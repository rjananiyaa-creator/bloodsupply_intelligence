# Blood Supply Intelligence

An intelligent blood supply management system designed for real-time inventory tracking, donor management, and handling hospital requisitions efficiently.

## 🚀 Features

* **Real-time Inventory Tracking:** Monitor blood types, availability, and expiration dates.
* **Donor Management:** Track donor history, eligibility, and schedule donations.
* **Hospital Requisitions:** Streamline emergency requests and fulfillment between blood banks and hospitals.

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript
* **Build Tool:** Vite
* **Package Manager:** Bun
